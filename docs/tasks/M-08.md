## USER GUIDE notes (for the readme, card P5-03)
- USER GUIDE: after a first install or a Master Reset, FDN stays PAUSED until you switch it on in the Artificial Life plugin settings. Setting a Distribution Centre does not switch it on. While FDN is paused the Config menu shows 'FDN Enabled: OFF' (red) at the top.
- USER GUIDE: v9.01 needs a fresh save; v8.04 saves are not supported.
- USER GUIDE: a dock can only become a Distribution Centre when it is within backbone range of the primary DC (the Add list only shows those docks). A DC that loses its link (for example after Make primary or a range change) stays a DC and shows a red 'Not linked to primary' mark on the Distribution Centre Network page.
- USER GUIDE: backbone range = multiplier x the smaller of the two DC ranges (Config, 'Backbone range multiplier', 1-5, default 2). DC range = base range (Config) + type (Player HQ +2, Equipment Dock 0, other docks -1), or the per-DC override on the DC page.
- USER GUIDE: Pass Surplus on a DC has no effect (DCs do not pass surplus to themselves); Maintain on a DC only affects Energy Cell pulls.
- USER GUIDE: Back returns to the page you came from; opening a page already in the history goes back to it; Esc = Back; Close menu exits all pages.
