# M-09: Trade sellers that refuse the player (notoriety)

- Phase: post-release fix (after tag v9.01 at 7e88a70)
- Cards: M-09a (diagnostic logging), M-09b (null-safe short log lines), M-09c (fix + docs)

## Finding
- M-09b log, Paranid sellers (Space Jewellery M, Crystal Fab M): the drone spawns docked, partner stock, home money, price and drone cargo room are all fine, and `buy` returns 0.
- In game the station shows most wares in red with "your notoriety is too low". Player relation is Neutral (rating 0); the ware needs a higher notoriety.
- Teladi Crystal Fab M (Ianamus Zura gamma): `is docking allowed` returns null for every drone type (trans=1, max > 0); treated as the same refusal.

## Script commands checked (compiler data x3fl.xml, rpncheck)
- `getNotoriety(race, race)` (726) and `$obj->getNotoriety(race)` (725) exist and compile: they return the notoriety value only.
- FL-only extras exist (raceGetRanking, getNotorietyLevel, getTitleFromRaceRank, getRaceRankPercentage).
- No command returns the notoriety a ware or station needs before trading, and no "is trading allowed" command exists. A pre-check is therefore not possible; the fix detects the refusal after the first refused buy.

## Fix (M-09c)
- `lib.LI.FDN.Trade` v1.3: block = local variable `LI.FDN.block.<ware>` on the partner set to the playing time, station appended to global array `al.LI.FDN.block`; set after a zero buy on the first load with the drone docked, partner stock > 0 and home money >= price, or when every drone type failed `is docking allowed` (buy mode only). A buy from a seller blocked less than 1800 s ago is skipped with `TRADE skip seller ...`. Sell mode is unchanged.
- `plugin.LI.FDN.Buy.Ware` v3.1: the find's exclude array is settings [8] plus every seller still blocked for the ware; a seller blocked during the pass is excluded and the same sector is searched again (max 5 per run).
- Logging: compact - `TRADE spawn ok`, two `TRADE reject` lines per type, three `TRADE buy` lines on a zero buy, `TRADE block ...` (3 lines) and `TRADE skip seller ...`; Buy.Ware debug lines `Buy skips N blocked seller(s)` and `Seller X blocked - searching again`.

## Test
- Load the save with Supply Debug on, wait one supply cycle. Expect at a Paranid seller: `TRADE buy returned n=0`, `TRADE block seller ... for 30 min: zero-buy`, then Buy.Ware `Seller ... blocked - searching again` and a buy from another seller (or `No seller found`). Next cycles: `Buy skips N blocked seller(s)`, no repeated drone at the blocked seller. After 30 min game time the seller is tried once again.
