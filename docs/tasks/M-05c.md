## Excerpts

### Contract
- Script `lib.LI.FDN.Route.Find`. Args: 0 from (Value) 'from', 1 to (Value) 'to'. Wait-free.
- Data: [35] = array of links, each `[dcA, dcB, jumps]` (written by the pasted Route.Build; a link works in both directions). Nodes = the DCs from Dc.List (at most 16, Matt's limit).
- Returns:
  - null: settings missing or < 40, `from` or `to` not in Dc.List, or no route;
  - an empty array (size 0) when `from` == `to`;
  - otherwise the legs in travel order: array of `[sender, receiver, jumps]`, starting at `from` and ending at `to`.
- Search (label setting, small n, all integer):
  1. `$nodes = Dc.List`, `$n = size of array $nodes`; arrays `$best` (INT jumps, -1 = unknown), `$prev` (index of the previous node, -1), `$hops` (INT), `$done` (0/1), each `= = array alloc: size=$n`; fill with a `while` loop stepping `inc $i =`.
  2. `$start = find $from in array: $nodes` and `$goal` the same way (VERIFY: `find ... in array:` returns the index or null; when unsure, find the index with a loop comparing elements).
  3. `$best[$start] = 0`, `$hops[$start] = 0`.
  4. Repeat `$n` times: pick the not-done node with the smallest known `$best` (loop over all nodes, copy elements to locals before comparing); if none, stop (flag); mark it done; for every link in [35] that touches it (copy `$link = $links[$k]`, then `$a = $link[0]`, `$b = $link[1]`, `$j = $link[2]`), the other end `$o`: when `$o` is a node, not done, `$hops[cur] + 1 <= 16`, and `$best[cur] + $j` is smaller than `$best[$o]` or `$best[$o]` is -1, set best, prev and hops.
  5. When `$best[$goal]` is -1 -> null. Otherwise walk `$prev` back from `$goal` to `$start`, building the legs, then reverse them (or insert at the front) so they are in travel order. Each leg's jumps is `$best[receiver] - $best[sender]`.
- Equal totals: keep the first one found (no extra tie rule).
- No break: every loop ends by its condition, using flag variables.

### Examples
- One DC (Matt's FL save): Route.Find(dc, dc) -> empty array; Route.Find(dc, other dock) -> null.
- Links [[A,B,3],[B,C,2],[A,C,7]]: A->C -> [[A,B,3],[B,C,2]] (5 jumps beats 7).
- Links [[A,B,3]] only: A->C -> null.
