## Key facts

- Learned in M-03 (compiler table and build): `create new array, arguments=` takes EXACTLY 5 arguments; never use it for other sizes. Build small arrays with `$a = = array alloc: size=3` (a literal or a plain variable, no arithmetic) and then `$a[0] = ...`, `$a[1] = ...`. Copy an array element into a plain variable before using it with `->` or as a call argument (`$dc.a = $list[$i]` then `$sec = $dc.a -> get sector`).
- Local variables: `$x = $obj -> get local variable: name='FDN.DC.Cfg'` and `= $obj -> set local variable: name='FDN.DC.Cfg' value=$arr` (null value clears it). Jumps: `$j = = get jumps from sector $a to sector $b`. Time: `$now = = playing time`.
- Test logging (pattern of test.LI.FDN.FL.Managed): first line to 9910 with append [TRUE] and 9911 with append [FALSE] (restart); every later line via a `Log.Sub:` that writes `write to log file 9910 append=[TRUE] value=$txt` and the same for 9911. Do NOT use lib.LI.FDN.Log in the test (it only writes when debug [7] is on and never writes 9911).
- Settings: `$g = [THIS] -> call script lib.LI.FDN.Cfg.Get :` returns the shared array; changing `$g[31]` changes the live settings, so save and restore every slot you touch and store with `set global variable: name='al.LI.FDN.event' value=$g`.
- House style (Matt's rules, always): a discarded call result is written ` = [THIS] -> call script ...` (leading space-equals), never `$null =`. No AND, OR, && or || (nest `if` blocks). No `!=` (use `if not $a == $b`). No array element inside a condition (copy it to a local first). No `->` or calls inside a condition (assign first, then test the variable). `null == null` is FALSE, so test with `is datatyp[ $x ] == DATATYPE_NULL`. No arithmetic inside `array alloc: size=`. Block balance: `if` lines (not counting `else if`) plus `while` lines must equal `end` lines. `return` inside a gosub sub ends the whole script: leave a sub with `endsub` only. Append with `append $x to array $a`.
- Every new or changed file: CRLF line endings, ASCII only, header in the usual form, and a change tag line ` * v9.01 D6 (M-03b): ...`. New scripts start at version 1.0. Use only get-commands that already appear in FDN sources or in this card; anything else needs `VERIFY:` and a stop.
