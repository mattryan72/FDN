## Excerpts

### Contract
- Script `lib.LI.FDN.Home`, Arg 0: station (Value) 'station'. Wait-free. Returns the home DC (a station) or null.
- Steps, in order:
  1. Settings missing -> return null.
  2. Settings smaller than 40 (save not upgraded yet): return [2] when `Is.Valid obj=[2] need.dock=[TRUE]` is [TRUE], else null.
  3. Station not a DATATYPE_STATION -> return null.
  4. `$list = Dc.List`; not an array or size 0 -> return null.
  5. `$hub = $station -> get local variable: name='FDN.Hub'`.
  6. When `$hub` is an array: `$h = $hub[0]`.
     - `$h` is null: the station was out of range at the last Scan -> return null (do NOT reassign; Scan does that).
     - `$h` is a station AND `find $h in array: $list` is true AND Is.Valid need.dock TRUE -> return `$h`.
     - otherwise (stale: DC removed or dead) -> go to step 7.
  7. `$home = Hub.Assign station=$station` (it writes a fresh FDN.Hub) and return `$home`.
- When `$hub` is not an array (never assigned) -> step 7.
- Use flag variables for the 'go to step 7' path (no break, no return inside a sub). Keep all logic in the main body or use subs that only set variables.
- Debug log one line only when step 7 runs: `Home: <station> reassigned -> <home>` (build the text in a local first).

### Examples (Matt's FL save has one DC, the Argon Equipment Dock)
- Factory with FDN.Hub = [DC, 2, t] -> DC.
- Factory with no FDN.Hub -> Hub.Assign runs -> DC (and FDN.Hub now exists).
- Factory with FDN.Hub = [null, -1, t] -> null.
- Factory with FDN.Hub = [old dock no longer in [30], 1, t] -> Hub.Assign result.
- Settings of size 30 -> [2].
