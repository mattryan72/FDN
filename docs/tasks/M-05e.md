## Key facts

- Lessons from M-05a-d (read twice):
  - Your editor goes stale after any shell or PowerShell write to a file. Never write a source file from a shell. Re-open the file before each edit, and edit with the editor only.
  - Make one small edit at a time, bottom of the file first (E4, E3, E2, E1), re-read the area after each edit and check the block balance.
  - Do not touch anything outside the four edits (comments, logs, Sell paths, buy lock). Keep every existing line you are not told to change, byte for byte.
  - New variables in a sub are shared with the main body (MSCI subs have no own scope), so pick names that are not used elsewhere: `$hub`, `$hj`, `$hub.jumps`, `$s.size`, `$leg.ok`, `$leg.deferred`, `$push.go`, `$dc.have`, `$dc.virt`, `$dc.phys`, `$pull.need`, `$pulled`, `$plan`.
- Library calls (argument names exactly): `lib.LI.FDN.Home : station=`; `lib.LI.FDN.Leg.Pay : ware= units= payer= served= jumps= backbone=`; `lib.LI.FDN.Pull : home= ware= need=`; `plugin.LI.FDN.Update.Ware : ware= amount= station= action=` ('add' -> units added, 'remove' -> units removed); `lib.LI.FDN.Log : text= caller=`.
- Commands you may use: `get local variable: name=`, `get amount of ware $w in cargo bay`, `size of array`, `is datatyp[ $x ] == DATATYPE_...`. Anything else: `VERIFY:` and stop.
- House rules (checked by a script): no AND/OR/&&/||; no `!=` (use `if not $a == $b`); no `break`/`continue`; no call, `->` or array element inside a condition or a string expression (copy into a local first); ` = [THIS] -> call script ...` for discarded results, never `$null =`; loops step with `inc $i =` / `dec $s =`, never `$i++`; no `return` inside a sub (only `endsub`); `null == null` is FALSE (use the DATATYPE_NULL test); never `==` on whole arrays; block balance if + while = end.
- File: keep CRLF, ASCII, no BOM. Header: `* Version: 4.0`, `* Date: 29/10/2026`, `* Tested: not tested`, and a change block ` * v9.01 D6 (M-05e): home DC via lib.LI.FDN.Home; Energy Cell cost via lib.LI.FDN.Leg.Pay before product push and resource supply; shortage pull via lib.LI.FDN.Pull before the buy; out of range -> skip` under the existing change blocks.
