### Rules for this card
- **Equality when off:** with [33] = 0 nothing is charged (Leg.Pay returns [TRUE] without calling Cost); with one DC (any [31]) the home of every station is [2], no pull or regroup runs. So with cost off and one DC every pass must move exactly what it moves today. Settings smaller than 40 (not yet upgraded) -> home = [2], no cost, no pull.
- **Who pays:** DC -> station: the home DC. Station -> DC: the receiving (home) DC. DC -> DC (pull, regroup): the sending DC of each leg, backbone rates. `served` = the factory or dock (null on DC -> DC legs).
- **Never partial:** cost is computed for the planned units and paid BEFORE any stock moves. When Leg.Pay returns [FALSE] the transfer is skipped whole (stock unchanged) and the deferred counter [37] is increased by 1. [37] is the per-tick deferred counter (DECIDED Q5.2, approved by Matt 29/10/2026): Supply.Start writes one logbook warning when [37] > 0 at the end of a tick and sets it back to 0.
- **Jumps:** station legs use `FDN.Hub`[1] (copy to a local; non-INT or < 0 -> treat as out of range). Backbone legs use the link jumps from [35].
- **Pull (shortage):** only when the home DC cannot cover the need above its own level (today's rule: stock - remote level [1]). Sources: the other DCs in route order (fewest total jumps over [35], no revisit, cap 16 hops). A source gives at most physical + virtual - max(floor, its EC-style protect for EC, its remote level [1] for other wares); never below the floor. Each leg along the route is its own all-or-nothing Leg.Pay + move; when a later leg defers, the stock stays at that intermediate DC (logged). At most 4 pulls per pass (literal constant).
- **Out of range:** home null -> the station is skipped (no product collected, no supply, no top-up), one debug log line `<station> skip: out of range` per pass, records untouched.
- **Network EC check:** every 600 s game time (literal constant; [36] = last check), for each DC below its EC maintain level pull EC from DCs above (protect + floor) using the same Pull library with ware = SS_WARE_ENERGY. Wait-free script STARTed by Supply.Start.
