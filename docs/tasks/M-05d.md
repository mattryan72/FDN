## Excerpts

### Contract
- Script `lib.LI.FDN.Pull`. Args: 0 home (Value) 'home', 1 ware (Value) 'ware', 2 need (Number) 'need'. Wait-free. Returns the INT number of units that reached `home` (0 when nothing moved).
- Uses (contracts, already written): `lib.LI.FDN.Route.Find : from= to=` -> legs `[[sender, receiver, jumps], ...]` in travel order, empty when from == to, null when no route; `lib.LI.FDN.Leg.Pay : ware= units= payer= served= jumps= backbone=` -> [TRUE] go / [FALSE] deferred.
- Steps:
  1. Bad input (settings < 40, home not a valid DC, need not an INT > 0) -> 0.
  2. `$list = Dc.List`. For every other DC `$src` in the list, `$legs = Route.Find from=$src to=$home`; skip null. Total jumps = sum of leg jumps.
  3. Visit sources nearest first (pick the smallest total each time from the not-visited ones), at most 4 sources (literal `$max.sources = 4`), while still needed > 0.
  4. For a source: `$rec = Ware.Rec station=$src ware=$ware create=[FALSE]`; no record -> skip. `$virt = $rec[0]` (non-INT -> 0), `$phys = $src -> get amount of ware $ware in cargo bay`, `$remote = $rec[1]` (INT > 0 else 0). Floor: `$cap = $src -> get max amount of ware $ware that can be stored in cargo bay`; pct = `FDN.DC.Cfg`[1] on `$src` when INT 0-100, else [34] when INT 0-100, else 25; `$floor = ( $cap * $pct + 99 ) / 100`. Level = the larger of `$floor` and `$remote`; for Energy Cells (`$ware == [SS_WARE_ENERGY]`) also `$rec[2]` maintain (INT > 0). Available = `$virt + $phys - level`; <= 0 -> skip. Take = smaller of available and still needed.
  5. Move leg by leg: for each leg `[$s, $r, $j]` in order: `$ok = Leg.Pay ware=$ware units=$take payer=$s served=null jumps=$j backbone=[TRUE]`; not [TRUE] -> stop this source (stock stays where it is, log it); else `$got = Update.Ware ware=$ware amount=$take station=$s action='remove'` (non-INT -> 0), then ` = Update.Ware ware=$ware amount=$got station=$r action='add'`, `$take = $got`; `$got` 0 -> stop this source.
  6. When the last leg ends at `home`, add `$take` to the result and subtract it from still needed. Debug log `backbone: <ware> <n> <source> -> <home> (<hops> hops, <jumps> j)`.
- One DC only (Matt's FL save) -> no other source -> 0.
- [33] = 0: Leg.Pay returns [TRUE] at once, so the pull works with no cost (equals the cost-off rule).

### Examples
- Home needs 500, source B (2 jumps) has 2000 above its level -> 500 moved, return 500.
- Source at or below its floor -> skipped, return 0.
- Two-leg route, second leg deferred -> the units stay at the middle DC, return 0, log line written.
