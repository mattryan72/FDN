## Excerpts

### Contract
- Script `lib.LI.FDN.Leg.Pay`. Args: 0 ware (Value) 'ware', 1 units (Number) 'units', 2 payer (Value) 'payer', 3 served (Value) 'served', 4 jumps (Number) 'jumps', 5 backbone (Value) 'backbone'. Wait-free.
- Returns [TRUE] when the transfer may go ahead (paid, or free), [FALSE] when it must be skipped whole (deferred). Callers move stock only after [TRUE] (never partial).
- Steps, in order:
  1. Settings missing -> [TRUE] (no cost system, today's behaviour).
  2. Size < 40 -> [TRUE].
  3. `$on = $al.Settings[33]`; when it is not 1 -> [TRUE]. (Cost off must behave exactly like today.)
  4. `units` not an INT or <= 0 -> [TRUE].
  5. `jumps` not an INT or < 0 -> use 0.
  6. `$cost = [THIS] -> call script lib.LI.FDN.Cost : ware=$ware units=$units jumps=$jumps dc=$payer backbone=$backbone`. Not an INT or <= 0 -> [TRUE].
  7. `$paid = [THIS] -> call script lib.LI.FDN.Cost.Pay : payer=$payer served=$served cost=$cost`.
  8. `$paid == [TRUE]` -> [TRUE].
  9. Otherwise: `$d = $al.Settings[37]`; not an INT -> 0; `inc $d =`; `$al.Settings[37] = $d`; `set global variable: name='al.LI.FDN.event' value=$al.Settings`; debug log `Leg.Pay: deferred <units> <ware> payer <payer> cost <cost>`; return [FALSE].
- Cost.Pay already writes the 9910 'Cost: deferred ...' line and FDN.Cost[3]; do not repeat that.
- [37] = deferred transfers this tick (approved by Matt 29/10/2026). Supply.Start shows the logbook warning (text 340) and resets it; not this script.

### Examples
- [33] = 0, any input -> [TRUE], Cost and Cost.Pay are NOT called, [37] unchanged.
- [33] = 1, 100 Energy Cells, 1 jump, payer has plenty -> [TRUE], the DC FDN.Cost[0] grows by the Cost value.
- [33] = 1, payer and network below protect -> [FALSE], [37] + 1, stock unchanged.
