* Script: lib.LI.FDN.Trade  (v901, engine 50)
* Desc: FDN v9.01 - Wait-free docked drone buy/sell between $home and an NPC partner station
* Arg 0: mode (String) 'mode'
* Arg 1: partner (Value) 'partner'
* Arg 2: ware (Value) 'ware'
* Arg 3: amount (Number) 'amount'
* Arg 4: home (Value) 'home'
* Arg 5: dest (Value) 'dest'
* Author: Logain Abler
* -----------------------------------------------------------------------------------
* Synchronous wait-free helper (Phase 2, R-T1 / B15). MSCI has no station-to-station trade
* command, so a drone is created already docked at $partner, trades one load at a time and
* is destructed in the same block - nothing ever waits between create ship and destruct.
* One exit label (Exit:); every path goes there. At most one drone exists at any moment.
* A log reason code is written via lib.LI.FDN.Log at every decision. Returns units traded,
* always an int >= 0, never null or negative (0 on any failure).
*
* Arguments:
* - mode (String): 'buy' = partner sells to $home/$dest; 'sell' = $home stock sold to partner
* - partner (Value): NPC station to trade with (owner race != Player)
* - ware (Value): ware to trade
* - amount (Number): requested units (> 0)
* - home (Value): player-owned station whose account pays/receives and holds the record
* - dest (Value): optional delivery station for 'buy' only; null = $home
*
* Returns values:
* - units actually traded (int >= 0); 0 on any guard failure, price check or spawn failure
*
* M-09c (fix): a buy whose drone is docked, with partner stock, money and cargo room, that still
* returns 0 means the seller refuses the player (in game the station shows 'your notoriety is
* too low'); a partner where 'is docking allowed' fails for every drone type is refused the same
* way. Trade then blocks that seller for this ware for 30 minutes game time (local variable
* 'LI.FDN.block.<ware>' on the partner; the station is listed in global 'al.LI.FDN.block'),
* logs it, and a buy from a blocked seller is skipped. Buy.Ware leaves blocked sellers out of
* its find. X3 has no script command for a ware's notoriety requirement, so this is detection
* after the first refused buy, not a pre-check. Diagnostic logging is the compact M-09a/b set.
*
* To Do - N/A
*
* Version: 1.3
* Date: 31/10/2026
* Tested: not tested (M-09c; M-09b showed n=0 buys at Paranid sellers with stock, money and cargo room)
* -----------------------------------------------------------------------------------

 * remove what was actually sold from the home's stock via Update.Ware (physical + virtual)
 $removed = [THIS] -> call script plugin.LI.FDN.Update.Ware : ware=$ware amount=$traded station=$home action='remove'
 if not is datatyp[ $removed ] == DATATYPE_INT
  $removed = 0
 else
  if $removed < 0
   $removed = 0
  end
 end
 * reconcile: if less was removed than sold, top the difference up from physical cargo first,
 * then virtual [0] - never taking either below zero. Home stock is only touched after a sale.
 if $removed < $traded
  $diff = $traded - $removed
  $h.phys = $home  ->  get amount of ware $ware in cargo bay
  if not is datatyp[ $h.phys ] == DATATYPE_INT
   $h.phys = 0
  end
  $h.virt = $rec[0]
  if not is datatyp[ $h.virt ] == DATATYPE_INT
   $h.virt = 0
  end
  * take as much of the difference from physical cargo as it can spare (floor at zero)
  $from.phys = 0
  if $h.phys > 0
   if $h.phys < $diff
    $from.phys = $h.phys
   else
    $from.phys = $diff
   end
  end
  * then take whatever is left from virtual stock (floor at zero)
  $left.diff = $diff - $from.phys
  $from.virt = 0
  if $h.virt > 0
   if $h.virt < $left.diff
    $from.virt = $h.virt
   else
    $from.virt = $left.diff
   end
  end
  * apply the reconciled removals to physical and virtual stock, then persist the record
  $new.phys = $h.phys - $from.phys
  if $from.phys > 0
   $neg.phys = - $from.phys
   = $home  ->  add $neg.phys units of $ware
  end
  $new.virt = $h.virt - $from.virt
  $rec[0] = $new.virt
  $home  ->  set local variable: name=$pointer value=$rec
  = [THIS] -> call script lib.LI.FDN.Log : text='TRADE reconcile diff=' + $diff + ' phys=' + $h.phys + ' virt=' + $h.virt caller=$s.name
 end
end
