* ---------- sub - set a station's EC availability to $target ($stn = the station) ----------
* v9.01 D6 (M-04c): floor 0, raise virtual +10000 over the saved value, maintain = virtual + physical - target (min 1) so exactly $target is available; Pay never drains below it
SetAvail.Sub:
$av.rec = [THIS] -> call script lib.LI.FDN.Ware.Rec : station=$stn ware=SS_WARE_ENERGY create=[FALSE]
if is datatyp[ $av.rec ] == DATATYPE_ARRAY
 * no record for this DC: nothing to set, fall through to endsub; the caller's virtual check will SKIP or FAIL
 $dc.cfg.work = $stn -> get local variable: name='FDN.DC.Cfg'
 if not is datatyp[ $dc.cfg.work ] == DATATYPE_ARRAY
  $dc.cfg.work = = array alloc: size=4
  $c0 = $dc.cfg.work[0]
  if not is datatyp[ $c0 ] == DATATYPE_INT
   $dc.cfg.work[0] = -1
  end
 end
 $dc.cfg.work[1] = 0
 $stn -> set local variable: name='FDN.DC.Cfg' value=$dc.cfg.work
 $av.rec[1] = 0
 if is datatyp[ $sav.dc.v0 ] == DATATYPE_INT
  $av.newvirt = $sav.dc.v0 + 10000
 else
  $av.newvirt = 10000
 end
 $av.rec[0] = $av.newvirt
 $av.phys = $stn -> get amount of ware SS_WARE_ENERGY in cargo bay
 if not is datatyp[ $av.phys ] == DATATYPE_INT
  $av.phys = 0
 end
 $av.maint = $av.rec[0] + $av.phys - $target
 if not is datatyp[ $av.maint ] == DATATYPE_INT
  $av.maint = 1
 end
 if $av.maint < 1
  $av.maint = 1
 end
 $av.rec[2] = $av.maint
end
endsub

* ---------- sub - run one Cost call and compare it with $exp ----------
* inputs: $ware $units $jumps $dcx $bb $exp $id (the caller also sets [33] before the gosub)
CostChk.Sub:
$cost.got = [THIS] -> call script lib.LI.FDN.Cost : ware=$ware units=$units jumps=$jumps dc=$dcx backbone=$bb
if not is datatyp[ $cost.got ] == DATATYPE_INT
 * the Cost lib must return an INT; anything else (null / error) fails this check rather than comparing wrong
 $ok = [FALSE]
 $det = 'Cost returned non-INT'
else
 $ok = [FALSE]
 if $cost.got == $exp
  $ok = [TRUE]
 end
 $det = 'got=' + $cost.got + ' expected=' + $exp
end
gosub Result.Sub:
endsub
