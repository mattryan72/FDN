* Script: lib.LI.FDN.Menu.WareRow (v901, engine 50)
* Desc: FDN v9.01 - Build one formatted ware row for the DC or dock station view
* Arg 0: station (Value) 'station'
* Arg 1: ware (Value) 'ware'
* Arg 2: is.dc (Boolean) 'is.dc'

* Author: Logain Abler
* -----------------------------------------------------------------------------------
* Synchronous wait-free helper (Phase 3). Single owner of the D8 row format duplicated
* in Wares.Summary as DC.Summary.Sub (12 columns, offsets -470/-380/-290/-200) and
* Dock.Summary.Sub (10 columns, offsets -380/-290/-200): both read the same 12-element
* ware record off the station and only differ in which settings are shown.

* One call returns a 2-element array [row, ['open.ware', station, ware]] where row is
* the array of columns - exactly what Wares.Summary wrapped around its two subs. The
* caller appends it straight to the menu array (arrays are references).

* The record is read via lib.LI.FDN.Ware.Rec : create=[TRUE], so a first sight of a ware
* creates the v9 default record - same side effect as Wares.Summary Build.Ware.Array.Sub,
* minus its add-1/add--1 cargo trick (the engine already counts an empty cargo
* bay as 0 units for 'get amount of ware in cargo bay', so the trick is not needed here).

* The v8 price fallbacks are kept: when buy-at [4] or sell-at [6] is not a positive number
* they display the current station price and the record is written back with that value,
* exactly as Wares.Summary does.

* Bad input returns null before any object command that could throw: settings missing
* (Cfg.Get), station not a DATATYPE_STATION or destroyed (datatype check first, P2 lesson),
* ware null, or Ware.Rec returning null. No waits, no STARTs - safe from a builder.

* Arguments:
* - station (Value): Station the row describes (the DC dock or any managed dock)
* - ware (Value): Ware the row shows
* - is.dc (Boolean): true = build the 12-column DC row; false/null = the 10-column dock row

* Returns values:
* - a 2-element array [row, ['open.ware', station, ware]] ('create new array' stops at
*   the first null, so no trailing nulls are stored) to append; null for bad input

* To Do - N/A

* Version: 1.0
* Date: 27/10/2026
* Tested: TC 27/10/2026
* -----------------------------------------------------------------------------------
