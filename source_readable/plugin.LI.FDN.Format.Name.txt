* Script: plugin.LI.FDN.Format.Name  (v3, engine 50)
* Desc: FDN v9.01 - Returns the menu text 'name [ID]' for an object (text 134)
* Arg 0: object (Value) 'object'
* Author: Logain Abler
* -----------------------------------------------------------------------------------
* Thin script called by every menu to format an object name. Keeps its name and argument.
* The 'name [ID] + sector' header line becomes lib.LI.FDN.Menu.ObjLine in Phase 3; until
* then this script returns only the 'name [ID]' text, exactly as v1 did.
*
* Expected values:
* - object: any existing object (station, ship, ...)
*
* Returns values:
* - the formatted text (page text 134), or null if there is no such object
*
* Version: 3.0
* Date: 26/10/2026
* Tested: TC 26/10/2026
* -----------------------------------------------------------------------------------
 * v9.01 D1 change (Format.Name): header via lib.LI.FDN.Cfg.Get; a missing or gone object now returns null instead of crashing on get name.
 * -----------------------------------------------------------------------------------

$al.Settings = [THIS] -> call script lib.LI.FDN.Cfg.Get :
if not $al.Settings
 return null
end
$PageID = $al.Settings[1]

if is datatyp[ $object ] == DATATYPE_NULL
 return null
end
$exists = $object  ->  exists
if not $exists
 return null
end

$name = $object  ->  get name
$id = $object  ->  get ID code
$return = = sprintf: pageid=$PageID textid=134, $name, $id, null, null, null
return $return
