* Script: plugin.LI.FDN.Supply.Factory  (v4, engine 50)
* Desc: FDNv9 - Supply Factory logic; called routine of Supply.Factory.Check (no START from the caller)
* Arg 0: factory (Value) 'factory'
* Arg 1: flag (Value) 'flag'

* Author: Logain Abler
* -----------------------------------------------------------------------------------
* This script is called synchronously by plugin.LI.FDN.Supply.Factory.Check - it runs as a
* routine inside that task and returns when done; the caller never STARTs it.
* It is used to handle supply between the factory and DC
* 
* Expected values:
* - Factory
* - Flag - 1 for Product, null/other for Resources
* 
* Returns values:
* - N/A (null)
* 
* To Do - N/A
* 
* Version: 4.0
* Date: 29/10/2026
* Tested: 2026-10-30 FL, cost off, one DC (cost-on paths not tested live)
* -----------------------------------------------------------------------------------
* v9.01 Phase 2 changes (P2-09b) - closes D1, D2 (one of nine), D3, B3, B11:
*   D1  Header switched to lib.LI.FDN.Cfg.Get (the only allowed copy of the settings fetch).
*   D2  Debug.Sub (the sub and its gosubs) deleted; every debug line goes through lib.LI.FDN.Log with $s.name as caller.
*   D3  The DC ware record is read via lib.LI.FDN.Ware.Rec : station=$dc ware=$ware create=[FALSE] -
*       null = no record, only that ware's buy is skipped; the text 4000 sprintf and the
*       $have.record flag are gone.
*   B3  DC validation reduced to one lib.LI.FDN.Is.Valid : obj=$dc need.dock=[TRUE] call near the
*       top (exists / owner race == Player / Dock class); while invalid, products are not taken
*       and no resource remove or buy is attempted. Supply.Start already paused FDN and told the
*       player when the DC goes bad - this only stops unchecked uses of $dc mid-tick.
*   B11 The manual busy flag in the factory settings [3] is replaced by lib.LI.FDN.Lock :
*       obj=$factory key='buy' action='try' timeout=120 (station local FDN.Busy.buy, stores
*       playing time, stale after 120 s). A null or FALSE result skips the buy this pass;
*       Buy.Ware releases it at its Exit label. The old 'busy for another N s' line becomes one
*       'Buy skipped - factory busy' line.
*   B31 (kept) Supply.Resource.Sub: when the factory already holds more than 3 cycles of a
*       resource in cargo, $required goes negative; it is clamped to 0 after the $max clamp so
*       the 'requires' debug line never shows a negative amount.
* -----------------------------------------------------------------------------------

* v9.01 Phase 2 changes (P2-14) - debug logging only, no behaviour change:
*   The shortfall line reads '<factory> short <n> of <ware> at DC; buy allowed=<yes/no/no record>'
*   (it used to say 'Buy N of ware ...' before the can-buy check was made).
*   The 'has', 'Remove' and 'requires' lines are only written for amounts above 0.
* -----------------------------------------------------------------------------------

* v9.01 D6 (M-05e) - home DC, Energy Cell cost, shortage pull:
 *   E1  $dc is resolved via lib.LI.FDN.Home : station=$factory instead of the AL plugin setting [2].
 *   E2  Jump-count gate before any ware moves: jumps from the factory's FDN.Hub[1]; Home null or bad
 *       jumps -> skip: out of range. A deferred leg pays no Energy Cells and moves nothing this pass.
 *   E3  Add.Product.Sub pushes only when $push.go (DC valid) and after paying Energy Cells via
 *       lib.LI.FDN.Leg.Pay : backbone=[FALSE]; the whole add/remove block sits inside the gate.
 *   E4  Supply.Resource.Sub computes $dc.have (virtual record [0] + physical cargo); a shortage is
 *       pulled over with one lib.LI.FDN.Pull per ware; Energy Cells are paid before Update.Ware
 *       'remove' and the supply/buy block runs only when not deferred.
* -----------------------------------------------------------------------------------

* v9.01 D1: standard header - lib.LI.FDN.Cfg.Get is the only allowed copy of the settings fetch
$script = = get script name
$s.name = $script
$al.Settings = [THIS] -> call script lib.LI.FDN.Cfg.Get :
if not $al.Settings
 return null
end
* Fetch values saved in the AL Plugin global variable:
* - DC
* array elements copied to locals before any condition (P1 lesson)
$dc = [THIS] -> call script lib.LI.FDN.Home : station=$factory
$debug.on = $al.Settings[7]
* -----------------------------------------------------------------------------------

* v9.01 B3: one call covers exists + player ownership + Dock class; Supply.Start owns telling
* the player when the DC goes bad, so there is no message here - this only stops unchecked
* uses of $dc in case a DC dies mid-tick (a routine runs atomically between waits)
* v9.01 D6 (M-05e): the DC must come from Home as a real station, and its jump count to home is read
 * straight off the factory's FDN.Hub[1]; a null Home result or a bad jumps value stops the routine
 * here before any ware is touched - the DC stays untouched instead of feeding an out-of-range plant.
$dc.valid = [FALSE]
if not is datatyp[ $dc ] == DATATYPE_NULL
 if is datatyp[ $dc ] == DATATYPE_STATION
  $dc.valid = [TRUE]
 end
end
$s.size = size of array $al.Settings
$hub.jumps = 0
if not $s.size < 40
 if $dc.valid
  $hub = $factory -> get local variable: name='FDN.Hub'
  if is datatyp[ $hub ] == DATATYPE_ARRAY
   $hj = $hub[1]
   if is datatyp[ $hj ] == DATATYPE_INT
    if not $hj < 0
     $hub.jumps = $hj
    else
     $dc.valid = [FALSE]
    end
   else
    $dc.valid = [FALSE]
   end
  else
   $dc.valid = [FALSE]
  end
 end
end
if not $dc.valid
 * debug
 if $debug.on
  if is datatyp[ $dc ] == DATATYPE_NULL
   $txt.log = $factory + ' skip: out of range'
  else
   $txt.log = $factory + ' skip: DC invalid'
  end
  = [THIS] -> call script lib.LI.FDN.Log : text=$txt.log caller=$s.name
 end
 return null
end
* -----------------------------------------------------------------------------------

* flag 1 is for products
if $flag == 1
 $ware = $factory  ->  get product ware
 gosub Add.Product.Sub:
 return null
 
else
 $ware.array = $factory  ->  get tradeable ware array from station
 $s = size of array $ware.array
 while $s > 0
  dec $s =
  $ware = $ware.array[$s]
  if $factory  ->  uses ware $ware as primary resource
   gosub Supply.Resource.Sub:
  end
 end
end
return null
* -----------------------------------------------------------------------------------

Add.Product.Sub:
* This sub is called to pass products to the DC
* For resources the wares will be added to the DC in the following order:
* - Physical Storage
* - Virtual Storage

* Get the product amount to be passed to the DC
$product.amount = $factory  ->  get amount of ware $ware in cargo bay
* debug
if $debug.on
 * v9.01 P2-14: only log when there is a product to pass (0 is noise)
 if $product.amount > 0
  $txt.log = $factory + ' has ' + $product.amount + ' of ' + $ware + ' to pass to DC'
  = [THIS] -> call script lib.LI.FDN.Log : text=$txt.log caller=$s.name
 end
end
* v9.01 B3: only touch the product if the DC is still valid (exists / player owned / Dock) - a bad DC
 * just stops this pass instead of returning out of the sub (that would end the whole call early)
$push.go = [TRUE]
if not $dc.valid
 $push.go = [FALSE]
 * debug
 if $debug.on
  $txt.log = 'DC invalid - product kept at ' + $factory
  = [THIS] -> call script lib.LI.FDN.Log : text=$txt.log caller=$s.name
 end
end
* v9.01 D6 (M-05e): the DC may only accept a product it can pay for in Energy Cells; a deferred leg
 * keeps the whole product at the factory this pass and the next tick retries once the DC has EC again
$leg.ok = [FALSE]
if $push.go
 if $product.amount > 0
  $leg.ok = [THIS] -> call script lib.LI.FDN.Leg.Pay : ware=$ware units=$product.amount payer=$dc served=$factory jumps=$hub.jumps backbone=[FALSE]
 end
end
* add to dc and take the amount Update.Ware says it accepted (only when the leg is ok)
if $leg.ok == [TRUE]
 $added.to.dc = null -> call script plugin.LI.FDN.Update.Ware : ware=$ware  amount=$product.amount  station=$dc  action='add'
* -----------------------------------------------------------------------------------

* v9.01 B3: remove from the factory only what was added to the DC (0 included) - only a null
* return falls back to v8 behaviour (e.g. Update.Ware before P1-04). Tighten after P2-12a:
* once 'add' returns real amounts on every path, drop the null fallback so a partial add can
* never leave wares in both stations.
$remove = - $product.amount
if not is datatyp[ $added.to.dc ] == DATATYPE_NULL
 $remove = - $added.to.dc
end
* Remove ware from factory
 = $factory  ->  add $remove units of $ware
* debug
if $debug.on
 * v9.01: negate on its own line - a unary minus inside a longer expression is mis-compiled
 $removed = - $remove
 * v9.01 P2-14: only log a real removal (0 is noise)
 if $removed > 0
  $txt.log = 'Remove ' + $removed + '  of ' + $ware + ' from ' + $factory
  = [THIS] -> call script lib.LI.FDN.Log : text=$txt.log caller=$s.name
 end
end
end
endsub
* -----------------------------------------------------------------------------------

Supply.Resource.Sub:
* This sub is called to pass resources to the factory
* For resources the wares will be removed from the DC in the following order:
* - Virtual Storage
* - Physical Storage
* - Buy if not in storage

* v9.01 B3: skip flag for this ware only (the sub is called per ware, so a fresh flag
* here never carries over) and it keeps the loop walking when we bail out below
$skip.ware = [FALSE]
if not $dc.valid
 * v9.01 B3: no resource remove or buy while the DC is invalid
 $skip.ware = [TRUE]
end

* calculate what th factory needs
$required = = $factory  ->  get number of resources per cycle for ware $ware
$current = $factory  ->  get amount of ware $ware in cargo bay
$required = ( $required * 3 ) - $current
$max = $factory  ->  get max amount of ware $ware that can be stored in cargo bay
if $max < $required
 $required = $max
end
* v9.01 B31: factory already holds more than 3 cycles - nothing is required (no negative amounts in the log)
if $required < 0
 $required = 0
end

* debug
if $debug.on
 if not $skip.ware
  * v9.01 P2-14: only log a real requirement (0 after the clamp is noise)
  if $required > 0
   $txt.log = $factory + ' requires ' + $required + '  of ' + $ware
   = [THIS] -> call script lib.LI.FDN.Log : text=$txt.log caller=$s.name
  end
 end
end

* if statement to ensure no negative values
if $required > 0
 * v9.01 D3: read the DC ware record via Ware.Rec with create=[FALSE]; null = no record yet, in
 * which case only this ware's buy is skipped and the remaining wares are still processed - do
 * not return from inside the sub here, that would end the whole call and skip them
 $ware.settings = [THIS] -> call script lib.LI.FDN.Ware.Rec : station=$dc ware=$ware create=[FALSE]

 * v9.01 D6 (M-05e): how much of this ware is already on the DC - virtual record [0] plus physical
 * cargo; a missing record or a non-int element counts as 0 so nothing below ever sees null
 $dc.virt = 0
 if is datatyp[ $ware.settings ] == DATATYPE_ARRAY
  $dc.v = $ware.settings[0]
  if is datatyp[ $dc.v ] == DATATYPE_INT
   $dc.virt = $dc.v
  end
 end
 $dc.phys = $dc  ->  get amount of ware $ware in cargo bay
 if not is datatyp[ $dc.phys ] == DATATYPE_INT
  $dc.phys = 0
 end
 $dc.have = $dc.virt + $dc.phys
 * v9.01 D6 (M-05e): pull the shortage over from elsewhere in the network before supplying - one Pull
 * per ware per pass (this sub runs once per ware). A missing record or a non-int pulled amount simply
 * leaves $dc.have as it was.
 if is datatyp[ $ware.settings ] == DATATYPE_ARRAY
  if $dc.have < $required
   $pull.need = $required - $dc.have
   $pulled = [THIS] -> call script lib.LI.FDN.Pull : home=$dc ware=$ware need=$pull.need
   if not is datatyp[ $pulled ] == DATATYPE_INT
    $pulled = 0
   end
   $dc.have = $dc.have + $pulled
  end
 end
 * v9.01 D6 (M-05e): plan to supply, capped to what is on hand; pay Energy Cells before anything moves;
 * a deferred leg means nothing is taken from the DC this pass and nothing is bought either (the DC holds
 * the stock so buying it from an NPC would waste credits)
 $plan = $required
 if $dc.have < $plan
  $plan = $dc.have
 end
 $from.dc = 0
 $leg.deferred = [FALSE]
 if not $skip.ware
  if $plan > 0
   $leg.ok = [THIS] -> call script lib.LI.FDN.Leg.Pay : ware=$ware units=$plan payer=$dc served=$factory jumps=$hub.jumps backbone=[FALSE]
  else
   $leg.ok = [TRUE]
  end
  if $leg.ok == [TRUE]
   $from.dc = null -> call script plugin.LI.FDN.Update.Ware : ware=$ware  amount=$plan  station=$dc  action='remove'
   if not is datatyp[ $from.dc ] == DATATYPE_INT
    $from.dc = 0
   end
  else
   $leg.deferred = [TRUE]
   * debug
   if $debug.on
    $txt.log = $factory + ' ' + $ware + ' skip: EC deferred, ' + $plan + ' not supplied'
    = [THIS] -> call script lib.LI.FDN.Log : text=$txt.log caller=$s.name
   end
  end
  * -----------------------------------------------------------------------------------
  
  

 if not $leg.deferred
  * check if the DC was able to supply the full amount if not call the buy script
  if $from.dc == $required
   = $factory  ->  add $required units of $ware
  else
   if $from.dc > 0
    = $factory  ->  add $from.dc units of $ware
   end
   * calculate what needs to be bought
   $required.buy = $required - $from.dc
   
   * v9.01 P2-14: one shortfall line per ware. The DC record was already read above with
   * create=[FALSE]; nothing is created or changed just for the log.
   if $debug.on
    $dbg.buy = 'no record'
    if $ware.settings
     $dbg.can = $ware.settings[3]
     $dbg.buy = 'no'
     if $dbg.can
      $dbg.buy = 'yes'
     end
    end
    $txt.log = $factory + ' short ' + $required.buy + ' of ' + $ware + ' at DC; buy allowed=' + $dbg.buy
    = [THIS] -> call script lib.LI.FDN.Log : text=$txt.log caller=$s.name
   end
   
   * v9.01 B3/D3: only look at the record when it exists (null would make [3] unreadable);
   * copy the element to a local before the condition (P1 lesson)
   if $ware.settings
    $can.buy = $ware.settings[3]
    if $can.buy
     * v9.01 B11: one lib call replaces the manual busy flag in FDN.Settings [3] - Lock stores
     * playing time in the station local FDN.Busy.buy and it goes stale after 120 s, so a
     * crashed Buy.Ware cannot wedge this factory. Buy.Ware releases it at its Exit: label.
     $lock = [THIS] -> call script lib.LI.FDN.Lock : obj=$factory key='buy' action='try' timeout=120
     if $lock
      * acquired - start the buy
      START  = null -> call script plugin.LI.FDN.Buy.Ware : factory=$factory  ware=$ware  amount=$required.buy
     end
     if not $lock
      * held (FALSE) or bad input (null) - skip this pass; stale after 120 s
      * debug
      if $debug.on
       $txt.log = 'Buy skipped - factory busy (buy lock held, stale after 120 s)'
       = [THIS] -> call script lib.LI.FDN.Log : text=$txt.log caller=$s.name
      end
     end
    end
   end
   
  end
end
 end
end
endsub

return null
