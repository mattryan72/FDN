* Script: plugin.LI.FDN.Supply.Dock.Check  (v901, engine 50)
* Desc: FDN v9.01 - Checks dock to be supplied
* Author: Logain Abler
* -----------------------------------------------------------------------------------
* This script is called by LI.FDN.Menu.Supply.Start script if there is a valid
* dock array stored in the AL Plugin variable
* The script contains the checks made on the docks before calling LI.FDN.Menu.Dock.Factory
* The script will also remove any non-existing or non-player-owned Docks from the stored array
* NOTE: no else / else if inside the while body - flags and separate ifs are used instead
* -----------------------------------------------------------------------------------
* v9.01 Phase 2 changes (P2-10a):
*   D1  Header switched to lib.LI.FDN.Cfg.Get (the only allowed copy of the settings fetch).
*       $PageID / $DebugID removed - nothing uses them once Debug.Sub is gone.
*   D2  Debug.Sub deleted; both clean-line debug entries go through lib.LI.FDN.Log with
*       $s.name as caller. The two reason texts are kept from v2.
*   B3  Per-dock validity is one call to lib.LI.FDN.Is.Valid : obj=$dock need.dock=[TRUE] -
*       missing, sold, captured or given-away stations (and non-Docks) are dropped from the
*       stored array [4]. Is.Valid null = does not exist, FALSE = not player owned / not a Dock; the clean line picks its text from that. The DC test before the loop is the same call with need.dock=[TRUE],
*       replacing the bare $dc -> exists check.
*   Loop, waits and START calls unchanged on this card - P2-10b owns Supply.Dock itself;
*   Supply.Start's START of this script also stays as-is (P2-08 comment).
* -----------------------------------------------------------------------------------
* v9.01 Phase 2 changes (P2-14) - debug logging only, no behaviour change:
*   One 'Dock pass start: docks=<n>' line per pass. The end-of-pass counts live on Supply.Dock's
*   own 'Pass finished' line, because each dock runs as its own task.
* -----------------------------------------------------------------------------------
* Expected values:
* - N/A the Dock array is stored in the AL Plugin variable
*
* Returns values:
* - N/A
*
* To Do - N/A
*
* Version: 3.0
* Date: 26/10/2026

 * v9.01 D6 (M-05g): DC pass (flag 1) for every valid DC in Dc.List; dock loop skips DCs

* v9.01 D1: standard header - lib.LI.FDN.Cfg.Get is the only allowed settings fetch (P2-01)
$script = = get script name
$s.name = $script
$al.Settings = [THIS] -> call script lib.LI.FDN.Cfg.Get :
if not $al.Settings
 return null
end

* Fetch values saved in the AL Plugin global variable:
* - dock array - holds all the known player docks
$dc = $al.Settings[2]
$dock.array = $al.Settings[4]

* v9.01 B3: Supply.Start validated the DC this tick and pauses FDN if it failed; no DC, nothing to do
if not $dc
 return null
end

* copy the debug flag to a local before any use (P1 lesson - array elements never in conditions)
$debug.on = $al.Settings[7]

$s = size of array $dock.array

* v9.01 P2-14: one line per dock pass (the per-dock results are logged by Supply.Dock itself)
if $debug.on
 $txt.log = 'Dock pass start: docks=' + $s
 = [THIS] -> call script lib.LI.FDN.Log : text=$txt.log caller=$s.name
end

* v9.01 D6 (M-05g): the DC pass (flag 1) runs for every valid DC in the cleaned list [30]
* (Dc.List validates each entry and puts [2] first). Older settings (< 40) return null -> [2] only.
$dc.list = [THIS] -> call script lib.LI.FDN.Dc.List :
if not is datatyp[ $dc.list ] == DATATYPE_ARRAY
 $dc.list = = array alloc: size=0
 $dc.valid = [THIS] -> call script lib.LI.FDN.Is.Valid : obj=$dc need.dock=[TRUE]
 if $dc.valid
  append $dc to array $dc.list
 end
end
$dl.size = size of array $dc.list
$dl.i = 0
while $dl.i < $dl.size
 $dc.pass = $dc.list[$dl.i]
 * this call the supply script for the dc which kicks off the sell part for the dc
 START  = null -> call script plugin.LI.FDN.Supply.Dock : dock=$dc.pass  flag=1
 inc $dl.i =
end

while $s > 0
 dec $s =
 $dock = $dock.array[$s]
 * v9.01 B3: one call covers exists + player ownership + Dock class (null for missing, FALSE otherwise)
 $valid = [THIS] -> call script lib.LI.FDN.Is.Valid : obj=$dock need.dock=[TRUE]
 if not $valid
  * missing, sold, captured or given away - remove from the stored array; the next entry has moved
  * into slot $s and is picked up by the dec at the top of the loop (v2 behaviour)
  remove element from array $dock.array at index $s
  if $debug.on
   * null = station does not exist; FALSE = exists but not player owned / not a Dock
   $txt.log = ' Clean from Dock Array - not player owned'
   if is datatyp[ $valid ] == DATATYPE_NULL
    $txt.log = ' Clean from Dock Array - does not exist'
   end
   = [THIS] -> call script lib.LI.FDN.Log : text=$txt.log caller=$s.name
  end
 end
 * v9.01 D6 (M-05g): a DC in the list already had its flag 1 pass above - no dock pass for it
 $is.dc = [FALSE]
 if $valid
  if find $dock in array: $dc.list
   $is.dc = [TRUE]
  end
 end
 if $is.dc
  $valid = [FALSE]
 end
 if $valid
  * -----------------------------------------------------------------------------------

  * Call plugin.LI.FDN.Supply.Dock:
  START  = null -> call script plugin.LI.FDN.Supply.Dock : dock=$dock  flag=null
  * ----------------------------------------------------------------------------------

 end
 * -----------------------------------------------------------------------------------
 
 = wait randomly from 1000 to 2000 ms
 * v9.01 B3/D2: no re-read of $debug.on or the DC here - Supply.Start owns both (DC validation +
 * pause every tick; the debug flag can only change via a menu, which cannot run mid-pass).
 * Re-checking dock/DC after this wait is Supply.Dock's own job (B12, P2-10b).
 * -----------------------------------------------------------------------------------
end
return null
