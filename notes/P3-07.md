# P3-07 - plugin.LI.FDN.Menu.Stations

Status: written by Cline, reviewed, built, installed, test.LI.FDN.Stations passed 4/4 on FL 27/10/2026 (AP branch, engine 60: 7 sectors, 16 factories, 2 docks besides the DC, 54 menu entries). TC branch not yet seen. Do not install Main.Menu before texts 302-307.

## What it is
View 2 of the menu. Called by Main.Menu as `Menu.Stations : menu=$menu obj=$obj` (obj is reserved
and not used). Appends to the menu in place and returns it. It replaces Menu.AP.Factory.List,
Menu.Factory.List, Menu.AP.Dock.List and Menu.Dock.List.

## Data
- Factories from settings [3], docks from [4], no scan. The DC is left out of the docks.
- Each station must pass lib.LI.FDN.Is.Valid (docks with need.dock = TRUE); a factory must also
  pass lib.LI.FDN.Is.Factory.
- Sectors are taken from the valid stations themselves (each once, sorted, then reversed as in v8),
  not from the cache [15], so a listed station can never be missing because of a stale cache.

## Layout
1. Heading 200 (Sectors:). AP and FL: Show All (198) and Hide All (199). Section.
2. One group per sector: its factories, a section, its docks.
   - AP and FL: native grouping (open=1) around the rows.
   - TC: a plain heading (sector in column 4) and a section after the rows. No show.factory toggles.
3. Factory row, 8 columns: '- ' + Format.Name, Products (160/162), Resources (161/163); returns
   ['open.factory', factory]. Fac.Cfg is called with auto.manage = 1, as v8 Factory.List did.
4. Dock row: '- ' + Format.Name; returns ['open.dock', dock].
5. Footer: heading 157, items 158/159 (product.all.on, resource.all.on), section, items 166/167
   (off), Auto Manage line 180/181, blank, stats 2000 (sectors), 2002 (factories, product, resource)
   and 2001 (docks), each shown only when its count is above 0.
6. Debug log 'Menu.Stations sectors n, factories n, docks n'.

## Decisions
- Menu.Command already handles product.all.on/off, resource.all.on/off, open.factory and open.dock.
- With no stations the menu shows the headings, the global commands and the Auto Manage line only.
