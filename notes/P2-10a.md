# Card P2-10a — `plugin.LI.FDN.Supply.Dock.Check` on the shared libraries

Status: not tested. Header kept as `Tested: not tested (P2-10a)`. Written 25/10/2026, Cline session.

## What it does
The per-dock supply pass, now on the Phase 2 shared libraries — same pattern as P2-09a (`Supply.Factory.Check` v4), but without a loop restructure (no budget/cursor; that is out of scope here):
1. Loads settings via the standard `lib.LI.FDN.Cfg.Get` header (D1) and takes `$s.name = $script` once for Log calls (P2-01 lesson). `$PageID` / `$DebugID` deleted — nothing uses them once Debug.Sub is gone.
2. Reads `[2]` (DC) and `[4]` (dock array); early return when the DC slot is null (Supply.Start owns DC validation + pause, kept from P1 B3).
3. Copies debug flag `[7]` to `$debug.on` before any use (P1 rule: no array elements in conditions).
4. DC pre-loop test reduced from `if $dc -> exists` to one `lib.LI.FDN.Is.Valid : obj=$dc need.dock=[TRUE]`; only on TRUE does it `START Supply.Dock flag=1`. If the DC died between ticks, no DC task starts (the already-early-returned null case covers a cleared one).
5. The v2 backward walk (`while $s > 0` / `dec $s =`) is unchanged: per-dock validity is now one `lib.LI.FDN.Is.Valid : obj=$dock need.dock=[TRUE]` call (B3) covering exists + player ownership + Dock class — this also drops non-Docks that ended up in `[4]`, which the v2/v3-P1 check did not catch. Non-TRUE entries are removed at index `$s`; the `dec` at loop top picks up the entry shifted into slot `$s` (v2 behaviour).
6. Debug: `Debug.Sub:` deleted; two separate `if`s (no else inside the while body, P2-09a pattern) log through `lib.LI.FDN.Log` with `$s.name`, keeping both v2 reason texts (' Clean from Dock Array - does not exist' / '- not player owned').
7. Valid docks still get `START Supply.Dock flag=null`; wait 1000–2000 ms per dock unchanged; the script never touches run-lock `[12]`.

## One behavioural note (vs v2)
Ownership is now read once inside Is.Valid at check time instead of re-tested after removal. A station that exists but changed owner *during this tick* logs 'does not exist' rather than 'not player owned'. The entry is removed either way; debug text only affected.

## Test steps
1. Fresh save, DC + ~5 docks, debug on → every tick: no new log lines unless an entry is bad; each dock still gets `START Supply.Dock flag=null`, the DC gets `flag=1` once per pass.
2. Sell one tracked dock mid-run (or capture it) → next visit to that slot: exactly one line `<time>;<script name>; Clean from Dock Array - not player owned`; array shrinks in place; the dock shifted into that slot is still checked this pass.
3. Destroy a station so its pointer dangles → `... Clean from Dock Array - does not exist`.
4. Sell/capture the DC between ticks → Supply.Start clears [2] and pauses first, so Dock.Check early-returns silently; expected: no crash, DC-invalid logbook line from Supply.Start. If a DC somehow dies mid-pass, at most one already-STARTed Supply.Dock task runs (its own B12 re-checks).
5. Put a non-Dock into [4] by hand (debug) → removed with the 'does not exist' reason text on first visit (Is.Valid need.dock=[TRUE]); array no longer contains it next tick.
6. Toggle debug off → identical behaviour, zero log lines.

## Compiler rules followed
- No `!=`, no `AND`/`OR`, no `&&`/`||`; the two reason branches are separate `if`s, not an else (P2-09a pattern).
- Leading `= ` on every `[THIS] -> call script …` that discards its return value (both Log calls); Is.Valid/Cfg.Get results stored.
- No inline `+` in any call-script argument (texts are literals here anyway).
- All array elements copied to locals before use (`$dc`, `$dock.array`, `$debug.on`).
- One-space-per-block indentation; CRLF line endings preserved per .gitattributes.
