# P4-06 - lib.LI.FDN.Is.FL.Managed v2

Date: 28/10/2026. Status: built, installed, tested on FL (test.LI.FDN.FL.Managed 6/6).

## What changed
- The Phase 2 stub (always FALSE) is replaced by the approved rule (17/10/2026, tests T9/T9b).
- Returns null if the argument is not a station or does not exist (Scan treats null as FALSE).
- Returns FALSE if the settings array is missing or shorter than 24, or [23] is not 3, so no FL-only command runs on AP or TC.
- On FL it reads the station local egosoft.stationmgr.time. TRUE only if it is a number and playing time minus it is 10 or less. Freshness is used, not existence, because FL never clears the local.
- Written by Cline from a card with the final code block; checked byte-wise (CRLF, ASCII, 61 lines, 8 if / 8 end). $now = = playing time is the correct MSCI form.

## Test (FL)
- test.LI.FDN.FL.Managed 6/6 PASS on a dock (Argon Equipment Dock, Aladna Hill): a) null and 'x' return null, c) no local gives FALSE, d) local = playing time gives TRUE, e) local 20 s old gives FALSE, f) non-number gives FALSE, g) [23] = 2 with a fresh local gives FALSE.
- The test sets the local and [23] on the live objects and restores both (RESTORED local=null [23]=3).

## Not seen
- A real station under Station Manager (the local was faked), and the Scan drop with texts 330/331/332 on a live factory, dock or DC.
- DC.Change refusing a Station Manager station with 'fl.managed' on a live run.
- AP and TC (they return FALSE by the [23] check, not run live).
