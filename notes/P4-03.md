# P4-03 - Setup v3: hotkey fallback and optional FL entries

Date: 27/10/2026. Status: source written, not built or tested.

## Files
- source_readable/plugin.LI.FDN.Setup.txt (v3): one new call at the very end, to Setup.Keys. The CPC entry (texts 101/102, script plugin.LI.FDN.Main.Menu) and the removal on stop are unchanged.
- source_readable/plugin.LI.FDN.Setup.Keys.txt (new): game flag, FL patch flag, hotkey register/unregister.
- source_readable/plugin.LI.FDN.Setup.FL.txt (new): script options entry, FL only; removes the old personal sidebar entry (see Sidebar finding).

## Why a separate Setup.Keys
al.LI.FDN.event calls Setup first and Upgrade after it. A v8 save still has a 12-entry settings array when Setup runs, and [21], [23] and [24] do not exist yet. Setup.Keys checks the size and returns on a small array. Upgrade (P4-04) grows the array and then calls Setup.Keys itself, so the hotkey appears on the first load after the upgrade and not the second. Setup restarts the log, so Upgrade cannot run before it without losing its log lines.

## Rules
- [23] = lib.LI.FDN.Game (1 TC, 2 AP, 3 FL). [24] = 1 when [23] is 3, else 0 (P4-02).
- [21] holds the hotkey id. Every call first unregisters the id in [21] (if it is an integer) and clears it, so a registration that survived a save is never doubled.
- Hotkey is registered only when [0] is TRUE. On stop [0] is FALSE, so the old hotkey is removed and none is added.
- Hotkey label is text 102 ("FDN Main Menu") on page 9910. No new text was added.
- Setup.FL runs only when [0] is TRUE and [24] is 1. Nothing is removed on stop.
- Sidebar finding (Matt, 27/10/2026): hovering the personal sidebar icon opened the FDN menu. Sidebar entries call their script as a menu script (obj, event, data), and Main.Menu opens on any call. The sidebar add (2741) was dropped; Setup.FL now runs emove sidebar custom entry, personal: id='plugin.LI.FDN.Main.Menu' (2743) to clear the entry already in the save. Wording from the compiler text table; not yet seen in game.
- Hotkey form: `register hotkey: page=$PageID id=102, to call script plugin.LI.FDN.Main.Menu` (the Script Editor form used by init.community.config). Sidebar and script options forms are copied from the same script.

## VERIFY in game

- Whether a registration survives a save/load (Setup.Keys copes either way).
- Both FL entries appear once and do not double up after reloading.
