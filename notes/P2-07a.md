## What it does
Synchronous, wait-free docked-drone buy/sell between `$home` and an NPC partner station (R-T1 / B15). MSCI has no station-to-station trade command, so a drone is created already docked at the partner, trades one load at a time, and is destructed in the same block — nothing ever waits between `create ship` and `destruct`. One exit label (`Exit:`); every path goes there; at most one drone exists at any moment. Returns units traded (int >= 0), 0 on any guard failure, price check or spawn failure.

## Files
- `source_readable/lib.LI.FDN.Trade.txt` (new, ~565 lines): the hardened trade helper.
  - Guards: settings via Cfg.Get; mode 'buy'/'sell'; amount int > 0; partner a non-Player station not in Foe relation to home; partner sector in the cached trade list (Sectors mode 3); `$home` and, on buy, `$dest` validated with `lib.LI.FDN.Is.Valid` BEFORE any `-> get relation`/trade call.
  - Drone type fallback: try settings [26], then each de-duplicated entry of [25] (each copied to a local first so a null is never appended), then the default Argon Mercury Super Freighter XL, then one TS fallback each for Argon and Paranid (`get ship type array` class=TS 2031, size read via `$fb.size`). Capped at 4 spawn attempts; a null candidate is skipped before `create ship` (T5: null spawns a Mammoth).
  - Each accepted drone is named (text 310), tagged (text 4102 = playing time) and homebased immediately (T6); accepted only if docking allowed, can transport the ware and max cargo > 0 — otherwise destructed (`show no explosion=[TRUE]`) and the next type tried; winner cached to [26].
  - Trade loop: at most [27] loads, each clamped to drone max; a null/<=0 result ends it. Buy delivers to `$dest`; sell reconciles via Update.Ware 'remove', topping the difference up from physical cargo first then virtual rec[0], never below zero (negative units passed as a local `$neg.phys`).
  - MSCI compliance: no `&&`/`||`, no `!=`, and no function calls inside conditions — drone existence uses an intermediate `$d.alive`; loops terminate via a `$done` flag.

## Notes
- `$traded` and `$drone` are initialised at the top so an early `goto Exit:` still returns a clean int 0 with no leftover drone.
- The buy/sell decision sits INSIDE the `else` of the "nothing left to trade" check, so a pass where `$remaining == 0` never re-runs a stale chunk (ghost-load fix).
