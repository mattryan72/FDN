# P3-08b - plugin.LI.FDN.Menu.Ware.Details (on the libs, B5 surplus row)

Status: tested FL 27/10/2026, test.LI.FDN.WareDetails 11/11 (AP branch), including the surplus cycle through Menu.Command. Written by Cline; leftover v8 subs removed and indent fixed by me.

## What changed
- Header block: lib.LI.FDN.Menu.ObjLine. Stock line (ware: physical/virtual): Menu.Row as an info line.
- Settings rows: lib.LI.FDN.Menu.Row / Menu.Toggle, same return values as v8
  (remote.cap, can.buy, buy.at, sell.cap, sell.at for the DC; maintain.cap, surplus, sell.cap, sell.at for a dock).
- Record read with Ware.Rec create=FALSE: opening the view never creates a record. A missing record returns the menu untouched.
- B5: the dock 'surplus' row shows Default (On/Off/v8 compatible) / On / Off, texts 321-324.
- The remove-ware block (old code had it twice) is one block; the three action buttons stay direct single-column items.
- Menu.Command: 'surplus' now cycles Default -> On -> Off -> Default (new Ware.Surplus.Sub); it was a plain on/off toggle.
