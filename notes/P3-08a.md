# P3-08a - plugin.LI.FDN.Menu.Factory.Details (on the libs)

Status: tested FL 27/10/2026, test.LI.FDN.FacDetails 6/6 (AP branch). Written by Cline; I restored the dropped products/resources split block and CRLF.

## What changed
- Header block (name, sector, blank line): lib.LI.FDN.Menu.ObjLine.
- Settings: lib.LI.FDN.Fac.Cfg with auto.manage null (get-or-create only; [2] is never set here).
- Product / Resource switches: lib.LI.FDN.Menu.Toggle with label text 138 and return values
  ['product', factory] / ['resource', factory] (Menu.Command already handles both).
- Guards: menu must be an array, settings must exist, value must be an existing station; otherwise the
  menu is returned untouched.
- Unchanged: products and resources list with the amount per cycle (texts 137/139), the two headings.

## Known differences from v8
- The Toggle row adds a section after each switch (Menu.Row does that for clickable rows).
- Main.Menu passes the factory as 'value' (argument names menu, value are unchanged).
