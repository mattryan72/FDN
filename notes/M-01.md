# M-01 - Read-only probe test.LI.FDN.Probe

Date: 28/10/2026. Card M-01 (multi-DC, range limit, Energy Cell transfer cost; see
docs/DESIGN_v9_direction.md, 'Decisions 2026-10-28'). The probe changes no game object
and no FDN setting. It only reads values and writes 'TEST Probe:' lines to log 9910 and
log 9911 (log 9911 is restarted at the start of the run).

Files: source_readable/test.LI.FDN.Probe.txt (readable source), src/scripts/test.LI.FDN.Probe.xml,
installed as addon2/scripts/test.LI.FDN.Probe.xml. No arguments, engine 50.

## What it probes and the command used

Command text is the Script Editor form; the XScript compiler id is in brackets.
Source of each form: the XScript compiler command text table (Data/0001-L044.xml) and,
where noted, existing FDN / v7.2 sources.

1. Jumps between sectors - `$j = = get jumps from sector $a to sector $b` (711; also used in
   reference/v7.2_readable). Logged: player sector to itself (expect 0), player sector to a
   null sector (result is logged as returned), and both directions between the player sector
   and the DC plus up to 3 stations from [3] and 5 docks from [4].
   Player sector: `$ps = = get player ship` (743), `$psec = $ps -> get sector` (703).
2. Ware volume - `$vol = = get volume of ware $w` (604). NOT in the FDN references or v8/v9
   sources; found only in the compiler command table. Matt: check the in-game result.
3. Transport class and average price - `get transport class of ware $w` (605, v8 Supply.Dock)
   and `get average price of ware $w` (629, v8 Main.Menu).
   Wares for 2 and 3: Energy Cells (SS_WARE_ENERGY), Ore (SS_WARE_ORE), a missile
   (SS_MISSILE_A), a big ware (shield SS_SHIELD_E), plus the first 2 wares of the DC's
   `get tradeable ware array from station` (1041). No Teladianium constant exists in the
   compiler tables, so Teladianium is only covered if it is one of the DC's first 2 wares.
4. Max storable amount on a dock - `$st -> get max amount of ware $w that can be stored in
   cargo bay` (621, v8 Supply.Factory) on the DC and on the first dock, for Energy Cells and
   one other ware; also `get amount of ware $w in cargo bay` (618) and the FDN record's
   virtual stock [0] (via lib.LI.FDN.Ware.Rec with create=[FALSE], read only), and whether
   the virtual stock is above the max.
5. Station type - `get ware type code of object` (707), `get object class` (700),
   `get maintype` (659), `get subtype` (660) for the DC and up to 5 docks. The type code is
   compared with SS_DOCK_P_HQ (Player HQ), SS_DOCK_P_TRADE (player trading station) and
   SS_DOCK_P_EQUIP (player equipment dock); anything else is logged as 'other' with its raw
   values. No Station Manager station type exists in the compiler tables; on FL the probe logs
   lib.LI.FDN.Is.FL.Managed for each station instead.

Game id comes from lib.LI.FDN.Game; the engine number from `script engine version`.

Limitation: an MSCI script cannot test at run time whether a command exists; a missing
command stops the script from loading. All commands above are base X3TC commands (ids
below 1100), so they should exist on TC, AP and FL. Items with no source (no DC, no docks,
no player sector) are logged as 'n/a'.

## How Matt runs it (same on TC, AP and FL)

1. Load the game you want to probe (TC, AP or FL) with a save where FDN is set up
   (a DC in settings [2] and some docks).
2. Make sure the Script Editor is enabled, open it and choose test.LI.FDN.Probe.
   Run it with no arguments (run-on object null).
3. Read the result in the game's profile folder:
   - FL: C:\Users\mattr\Documents\Egosoft\X3FL\log09911.txt (full run), log09910.txt (appended)
   - TC/AP: log09911.txt in that game's own Egosoft profile folder (VERIFY the folder name
     for TC and AP on this PC).
4. Copy log09911.txt somewhere before running the probe on the next game.

## Results on FL (Matt, 28/10/2026, game=3 engine=60)

- Jumps: `get jumps from sector $a to sector $b` works. Same sector = 0, null sector = null, symmetric both ways. Player in Aladna Hill: Argon Prime alpha 10, Argon Prime gamma 11, Akeela's Beacon 1. Unreachable sector not tested.
- Volume (`get volume of ware`) works: Energy Cells 1, Ore 8 (class XL), Mosquito Missile 1, 1 GJ Shield 77 (XL), Cloth Rimes 2, Delexian Wheat 2.
- Transport class returns a text (Small Containers S, Extra Large Containers XL). Average price: Energy Cells 16, Ore 128, Mosquito 168, 1 GJ Shield 303844, Cloth Rimes 292, Delexian Wheat 32.
- Max storable works on docks: Equipment Dock EC 15000 (physical 15000, virtual 413161, so virtual is above max), Cloth Rimes 2500. HQ EC 1500000 (physical 8000), Cloth Rimes 746000. Virtual stock is not capped by capacity, so the reserve floor must test physical + virtual.
- Station type: the SS_DOCK_P_* constants did not match (kind=other for both). Equipment Dock: class "Equipment Dock", maintype 5, subtype 6. HQ: class "Headquarters", maintype 5, subtype 62. Trading station subtype not seen. FL Station Manager = 0 for all (correct). Use class text or subtype numbers for the H multiplier.
- TC and AP not run yet.
