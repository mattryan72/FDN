# P3-08c - plugin.LI.FDN.Config.Menu (on the libs, B5 surplus default row)

Status: written by Cline, repaired by me (CRLF, missing Add DC heading read, empty if branch); tested FL 27/10/2026, test.LI.FDN.ConfigMenu 9/10 (script-driven; the new Main.Menu is not installed yet).

The one FAIL (case b, 'no DC ObjLine') is a test-side detection problem, not a menu fault: the menu size is identical with and without a DC (24 = 24) although the no-DC build has 3 set.dc rows and the DC build 2, which only adds up if the DC build contains the 2 ObjLine entries. Case d reports objline=0 as expected. Not worth a re-run; Menu.ObjLine itself was tested in P3-02.

## What changed
- Guards: menu must be an array, settings come from lib.LI.FDN.Cfg.Get (the old direct read of al.LI.FDN.event is gone).
- DC choice: no valid DC shows info text 118 and the Add DC list (heading 123); a valid DC shows info text 129, lib.LI.FDN.Menu.ObjLine and the Change DC list (heading 124).
- Both lists use one sub (Dock.List.Sub). Every row is a Menu.Row [name, sector] returning ['set.dc', dock]; this replaces add.dc and change.dc. Docks are all player docks (v8 command), each checked with Is.Valid need.dock=TRUE.
- Switch rows use Menu.Toggle with one-element array return values: ['dynamic.dc'], ['dynamic.dock'], ['auto'], ['debug']. The dock-list switch stays out, as in v8.
- B5: new Global Options row 'surplus.default' (label 320, value 321 On / 322 Off / 323 v8 compatible from settings [28], null counts as On, return ['surplus.default']) followed by the help text 325.
- Master Reset stays a direct single-column item returning 'master.reset'.
- Dropped: the dead read of text 103 and the dead trailing return null.
- Menu.Command: 'debug' is now a plain on/off toggle of settings [7] (it cycled -1, 1, 0 by mistake; lib.LI.FDN.Log only tests true or false). Debug.Cycle.Sub removed.

## Needs before an in-game check
- Texts 320-325 on page 9910 (not in the XML yet). Without them the surplus row shows blank.
- Menu.Command and Main.Menu (P3-05) must be rebuilt/installed for the view to open.

## Known differences from v8
- The DC lists no longer use add.dc / change.dc; Menu.Command's set.dc confirms and calls DC.Change.
- Each settings row is followed by a section (Menu.Row behaviour).
