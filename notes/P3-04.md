# P3-04 - plugin.LI.FDN.Menu.Command

Status: written, not built or tested. Needs plugin.LI.FDN.DC.Change (P3-04b) for set.dc.

## What it is
New plugin script `plugin.LI.FDN.Menu.Command(stack, return)`. Main.Menu (P3-05) passes the
local view stack and the menu return value. The script returns the NEW stack (array of
[view, obj, ware]) or null to close the menu. No globals, no waits, no 'continue'.

View numbers (v8 settings [5]): 1 DC, 2 Stations, 4 Factory.Details, 5 Dock, 6 Ware.Details,
7 Config.Menu. View 3 is retired.

## Return value shapes
- Array [command, value, ware, extra], missing parts stay null (sizes are checked first).
- A plain string = global action. -1 (Escape) is treated as 'back'.

## Commands
Navigation (push an entry and return the longer stack):
- open.dc [1, dc], open.stations [2, value], open.factory [4, value], open.dock [5, value],
  open.ware [6, value, ware], open.config [7] (array or string form).
- back / Escape: pop the last entry; null when only one entry is left.

Edit commands (return the same stack):
- Caps: remote.cap [1], maintain.cap [2], sell.cap [5] - text 182, Var/Number, a negative
  value clears the cap, a cancelled prompt changes nothing.
- Prices: buy.at [4], sell.at [6] - text 183 (min, avg, max), value must be within min..max.
- Toggles: can.buy [3], surplus [7] (ware record), product [0] / resource [1] (factory local,
  text 4001), auto [9], dynamic.dc / dynamic.dock.list / dynamic.dock ([6][0..2]).
- Stock: to.physical / to.virtual (v8 Regroom.Ware.Sub, null-safe virtual count).
- move.ware: same call as v8 (plugin.LI.FDN.Move.Ware ware, source).
- add.ware: text 197 prompt, record created via Ware.Rec create=[TRUE], Reg.Add.
- product.all.on/off, resource.all.on/off: all factories in [3], with datatype and exists guards.
- debug [7]: -1 -> 1 -> 0 -> -1 (null = -1). surplus.default [28]: 1 -> 0 -> 2 -> 1 (null = 1).

Commands that return a NEW stack:
- remove.ware: confirm (text 300) first, then re-read physical + virtual stock; if above 0 it
  logs text 342 and deletes nothing. On success it pops the ware view.
- master.reset: confirm (text 186), plugin.LI.FDN.Reset, then [[1, dc]] or [[7]] when no DC left.
- set.dc: Is.Valid need.dock=[TRUE], one confirm (text 351) only if a DC is already set, then
  plugin.LI.FDN.DC.Change old=.. new=.. (it owns the settings [2] write). 'busy' logs text 352
  and keeps the stack. Success: Reg.Add and [[1, dock]].

Unknown commands return the same stack.

## Shared helper subs
Ware.Prep.Sub (station check via Is.Valid, record via Ware.Rec create=[TRUE], pointer from
text 4000) and Ware.Save.Sub (write the record back, Reg.Add, one log line, publish settings).

## Removed v8 commands
switch.menu, show.factory, show.type.dc, show.type.dock, add.dc, change.dc (merged into set.dc).
