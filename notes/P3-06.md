# P3-06 - plugin.LI.FDN.Menu.Station

Status: built, installed, builder test passed on FL 27/10/2026 (7/7, AP branch: engine 60). TC branch not yet seen. Do not install Main.Menu before P3-07 and texts 302-307.

## What it is
One builder for the DC view (view 1) and the dock view (view 5), called by Main.Menu as
`Menu.Station : menu=$menu view=$view obj=$obj`. It appends to the menu in place and returns it.
It replaces Menu.AP.DC.Details, Menu.AP.Dock.Details, Menu.DC.Details and Menu.Dock.Details.

## Layout
1. DC only: info line text 129 and a blank line.
2. Menu.ObjLine: 'Name [ID]' with sector, then a blank line.
3. Credits heading (text 146 and 'Cr: x', text 202).
4. AP and FL only: Show All (198) and Hide All (199) with menu return values.
5. One group per main type from Sort.Wares, wares in the v8 order (last to first):
   - AP and FL: native grouping (open=1), a non selectable column header row, the ware rows.
   - TC: plain heading, the column header as an info line, the ware rows, a section.
   - DC header columns: 201, 142, 144, 143, 145, 140. Dock: 201, 147, 143, 145, 140.
6. Add Ware: heading 195, item 196, return value ['add.ware', station].
7. DC only: heading 164, item 165, return value 'open.config'.

## Decisions
- No v8 show.type rows on any game version (Menu.Command removed show.type.dc and show.type.dock).
  TC has no native groups, so a TC type is always expanded.
- Rows come from lib.LI.FDN.Menu.WareRow (is.dc = view 1). A first sight of a ware creates its
  default record, same as v8 Wares.Summary.
- No waits and no STARTs. Main.Menu starts the updater.

## Live-update contract for P3-09
Each WareRow result is stored in the global named by text 5000 (id, ware) and the credits
array in text 5001 (id). The menu holds the same arrays, so Menu.Refresh edits them in place:
row[0][1] name, [3] remote, [5] buy-at, [7] sell cap, [9] sell-at, [11] storage (DC row),
and credits [3]. The old DC.Details_D / Dock.Details_D must NOT be started with this builder:
their Write.Menu.Global.Sub would replace the globals with arrays the menu does not hold.
Main.Menu switches to Menu.Refresh in P3-09.
