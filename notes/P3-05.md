# P3-05 - plugin.LI.FDN.Main.Menu (controller)

Status: written, not built or tested. Do not install before P3-06, P3-07 and texts 302-307.

## What it is
Main.Menu keeps only the controller loop. Per pass: read settings (Cfg.Get), take the top
entry of the local stack [view, obj, ware], START an updater if needed, build the view with
one builder, store [5], open the menu, call Menu.Command with the return value and assign
the returned stack. Null or an empty stack closes the menu (log, [5] = null, START Cleanup).

## Views and builders
| view | builder | arguments |
|---|---|---|
| 1 DC, 5 Dock | plugin.LI.FDN.Menu.Station (P3-06, new) | menu, view, obj |
| 2 Stations | plugin.LI.FDN.Menu.Stations (P3-07, new) | menu, obj |
| 4 Factory Details | plugin.LI.FDN.Menu.Factory.Details | menu, value=obj |
| 6 Ware Details | plugin.LI.FDN.Menu.Ware.Details | menu, value=obj, ware |
| 7 Config | plugin.LI.FDN.Config.Menu | menu |
Each builder fills the menu in place or returns it; Main.Menu uses the return only when it is an array.

## Rules kept from v8
- B8: token [20] bumped on every open and again before each updater START. Updater only on
  entering view 1 or 5 or a different station (same view and same obj = no START).
- Opening stack [[1, DC, null]], or [[7, null, null]] without a DC. With no DC set the stack
  is forced to Config on every pass, as in v8.
- Info menu (maxoptions=2) for views 1, 2 and 5, plain custom menu for the others.

## Removed
Command cascade, the -1 view table, header 'Switch to' row, $called.by, $dock.called.by,
$factory.show.array, and the subs Ware.User.Input, Add.Ware, Regroom.Ware, Remove.Ware,
Global.Factory (all now in Menu.Command).
