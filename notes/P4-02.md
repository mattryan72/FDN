# P4-02: FL patch feature flag [24]

Date: 27/10/2026. Decision by Matt: [24] is 1 when `lib.LI.FDN.Game` returns 3 (script engine 60 or more), otherwise 0.

## Rules
- [24] is set by the same callers that set [23] (game): plugin.LI.FDN.Upgrade (P4-04) on a v8 save and plugin.LI.FDN.Setup (P4-03) at start-up. They call lib.LI.FDN.Game once, store the result in [23], then store `1` in [24] if it is 3, otherwise `0`. Nothing writes [24] yet.
- Every command that exists only in the FL Unofficial Patch (`add script selection option`, `add sidebar custom entry`, `get dock storage wares`, `add object info menu` and similar) goes in its own small script and is called only when [24] is 1. Never inline in a shared script, so a failure stays inside that script. `plugin.LI.FDN.FL.Remove.Tradeable` already works this way (Menu.Command tests `engine >= 60` inline today; later it can read [24] instead).
- A missing or null [24] counts as 0.
- Nothing in the settings array reads [24] today, so no existing behaviour changes.

## Known weakness (VERIFY)
The test is not certain. Only patched FL 1.3.20 has been measured (engine 60). If unpatched FL also reports 60 or more, [24] would be 1 without the patch, and the patch-only scripts would fail when called. They fail alone and log the error; the rest of FDN is unaffected. Fix if it happens: raise the threshold or add a second signal, after someone runs the T7 test on unpatched FL.
