# P5-02: Version bump list (28/10/2026)

Source: notes/script_versions.txt (generated from the installed addon2 scripts, which match src/scripts byte for byte). Draft by Cline, checked and corrected by the assistant.

## Decisions

1. Every shipping script gets `<version>` 901. No current version is 901 or higher, so there is no "+1" case.
2. Descriptions start with `FDN v9.01 - ` (plain hyphen, as in the existing scripts; keeps the XML ASCII). The old prefix (`FDNv9 -`, `FDN v8 -`, `FDNv8 -`, `v4`) is replaced. The wording after the prefix is kept as in the installed scripts.
3. `lib.BW.isAP` (Bullwinkle) is not changed.
4. Text 100 stays `Logain Industries: \033GFDN\033X`. The plugin list shows "v9.01" because `al.LI.FDN.event` appends it at runtime. Changing text 100 as well would show "v9.01 v9.01". (Still to confirm in game that the list shows it.)
5. All 9 P3-10 stubs ship (they return null so old saves find the script names). They are marked STUB in the table.
6. Test scripts (`test.LI.FDN.*`, `plugin.LI.FDN.T6.KillHandler`) do not ship and are not bumped.
7. `Wares.Summary` description typo "Returnd" corrected to "Returned".

## How it is applied (not done yet)

A script edit, anchor-checked, on three copies of each file: `src/scripts/<name>.xml`, the installed addon2 copy, and the header lines of `source_readable/<name>.txt`. In each XML the version and description appear twice: in the `<version>` and `<description>` tags and inside the codearray (array element 3 = version, element 2 = description). Both places must change or the compiled script and its header disagree. Backups `.bak-p502` are taken first; hashes are checked after.
