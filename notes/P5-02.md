# P5-02: Version bump list (31/10/2026, replaces the 28/10 draft)

Source: the 78 non-test scripts in `src/scripts/` at commit 92517d2 (M-08r-s), working tree copies, which match the installed addon2 copies byte for byte. Built and checked by the assistant (card P5-02).

## Decisions

1. Every shipping FDN script gets `<version>` 901 (no script was at 901 or higher). The version is changed in both places in the XML: the `<version>` tag and codearray element 3.
2. Descriptions start with `FDN v9.01 - ` (plain hyphen, ASCII). Old prefixes replaced: `FDNv9 - `, `FDN v9 - `, `v4 ` (register). The words after the prefix are kept (`<description>` and codearray element 2 both changed).
3. `lib.BW.isAP` (Bullwinkle) is shipped unchanged.
4. Text 100 stays `Logain Industries: \033GFDN\033X`; `al.LI.FDN.event` appends ' v9.01' to the plugin description at runtime (P4-05). No text change in this card.
5. All 9 P3-10 stubs ship (they return null so old saves find the script names).
6. Not shipped and not bumped: every `test.LI.FDN.*` script and `plugin.LI.FDN.T6.KillHandler`.
7. `plugin.LI.FDN.Wares.Summary`: description typo 'Returnd' corrected to 'Returned'.
8. `source_readable/<name>.txt`: only the two header lines change - `* Script: <name> (v901, ...)` and the `* Desc:` prefix (its own wording kept). Five readable files are left unchanged because check_source already fails them and the apply tool refuses a failing file: `lib.LI.FDN.Ware.Rec.txt` and `plugin.LI.FDN.Scan.txt` (`$null = ... call script` lines) and `al.plugin.LI.FDN.register.txt`, `plugin.LI.FDN.Cleanup.txt`, `plugin.LI.FDN.Setup.txt` (LF line endings in the working tree). Their XML is still bumped. Old flags, deferred.
9. The XML change was verified by decompiling every old and new XML: the only differences are `#VERSION` and `#DESCRIPTION`.

## Description differences (XML vs readable source, cosmetic, left as they are)

The compiled description and the readable `* Desc:` line differ in wording for these scripts (both now start `FDN v9.01 - `): `lib.LI.FDN.Cost.Pay`, `lib.LI.FDN.Menu.ObjLine`, `lib.LI.FDN.Menu.Row`, `lib.LI.FDN.Menu.Toggle`, `lib.LI.FDN.Menu.WareRow`, `lib.LI.FDN.Pull`, `lib.LI.FDN.Route.Find`, `plugin.LI.FDN.Buy.Ware`, `plugin.LI.FDN.DC.Change`, `plugin.LI.FDN.EC.Regroup`, `plugin.LI.FDN.Format.Name`, `plugin.LI.FDN.Menu.Command`, `plugin.LI.FDN.Sector.Array`, `plugin.LI.FDN.Sell.Ware`, `plugin.LI.FDN.Supply.Dock.Check`, `plugin.LI.FDN.Supply.Factory.Check`, `plugin.LI.FDN.Update.Ware`.
