# P4-08 - Whole-project command review (v9.01 vs v8.04-baseline)

Date: 28/10/2026. Read-only review. Method: every non-comment, non-blank line of
source_readable/*.txt (v9 working tree, 61 files) and of every file in
`git ls-tree -r --name-only v8.04-baseline source_readable` (32 files, via git show)
was reduced to a command shape by a script:

- the old 3-digit listing numbers ('029  ') were dropped;
- assignment targets ('$x = ', '$x = = ', ' = ' discard) were dropped;
- $variables, numbers, 'strings', [CONSTANTS], DATATYPE_* were replaced by placeholders;
- race names, ship/station class names, the ware constant, script names after
  'script=' / 'to call script' and label names were also replaced by placeholders;
- pure expressions (only variables, constants and operators) became '<expr>'.

The two sets were then diffed and the result was reviewed by hand. 'TESTED' below
means the file carries a '* Tested:' header with a date (quoted). It says the file ran
in game on that build; it does not prove that every branch ran, and branch caveats
from the stamp are quoted. Scripts that exist only as XML (most test.* scripts were
written as .xs and are not in source_readable) are not covered.
