# P4-01: lib.LI.FDN.Game

Date: 27/10/2026. Tag [D6].

## What it does
`lib.LI.FDN.Game` (no arguments) reads `script engine version` and returns 1 (TC), 2 (AP) or 3 (FL):

| Engine | Result |
|---|---|
| 60 or more | 3 (FL) |
| 50 to 59 | 2 (AP) |
| below 50 | 1 (TC) |

Only >= is used, never ==. It reads no settings and writes nothing. The caller stores the result in settings [23]: plugin.LI.FDN.Upgrade (P4-04) on a v8 save and plugin.LI.FDN.Setup (P4-03) at start-up. Nothing stores it yet.

## Assumptions
- FL 1.3 with Unofficial Patch 1.3.20 is engine 60 (test T7, Matt's game). TC 3.2 = 44 and AP 2.0 = 52 come from the v8 comment in lib.BW.isAP.
- VERIFY: the AP 3.3 value, and vanilla FL 1.3 without the patch, which may be below 60 and would be reported as AP. Only the patched FL value has been measured. If unpatched FL is below 60, the FL threshold has to come down (Matt would need to run the T7 test there).

## Not changed
- lib.BW.isAP is untouched (it belongs to Bullwinkle). Menu.Station and Menu.Stations still call it; switching them to lib.LI.FDN.Game is not part of this card. Menu.Command already tests `engine >= 60` inline for the FL-only tradeable removal.
