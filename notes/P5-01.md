# P5-01 - v9.01 Test Checklist

Date: 28/10/2026. Purpose: the manual in-game pass that closes out Phase 4 and
re-checks every "Not tested / Not seen" item carried from Phases 2, 3 and 4.
Log file for all checks below is `log09910.txt` (the FDN log restarted by Setup on
every load). Where a line is quoted it was copied verbatim from the source; where an
expected behaviour has no known log line it is marked `VERIFY: check the log for ...`.

## Assumptions

- The build under test carries every P2, P3 and P4 change (new Main.Menu controller,
  Menu.Station / Menu.Stations / Menu.Refresh, DC.Change, Upgrade v2 + Upgrade.Records,
  Setup.Keys + Setup.FL, Is.FL.Managed v2, B5 surplus engine). If any of those is not in
  the build, say so before starting - several rows depend on it.
- "Fresh install" means a save with no FDN data at all (al.LI.FDN.event unset) so Setup
  runs from scratch. "v8.04 baseline save" means the existing v8.04 baseline save loaded
  into the same game, so Upgrade does the migration on load.
- Debug logging is controlled by settings [7]; most supply/log rows only appear when it is
  ON. Set debug ON (Config menu) at the start of a session unless a row says otherwise.
- FDN "on" = settings [0] TRUE; FDN "off" = [0] FALSE (toggled from Config).
- The Station Manager checks (12, 13) need FL with the Unofficial Patch and a real station
  handed to Station Manager (the Is.FL.Managed test only faked the local).

## Decisions from Matt (28/10/2026)

- Games: all versions are in scope - TC (original Terran Conflict, [23] = 1), AP (Albion Prelude, [23] = 2) and FL (Farnham's Legacy, [23] = 3). Matt has a v8.04 baseline save on FL only; for TC and AP, install v8.04 (git tag v8.04-baseline) on that game, play a short session with FDN set up, save, then install v9.01 over it.
- TC is in scope: it must install, upgrade and run supply with no FL-only commands. The untested TC branches (plain headings in Menu.Station and Menu.Stations, hotkey, Setup, Upgrade) are checked there.
- Station Manager rows (12, 13): Matt's description of the step is "disable FDN product and resource management on the station, or if Station Manager is enabled, disable FDN product and resource management for that station". Steps below say to put the station under FL Station Manager; the exact menu wording is VERIFY by Matt in game.
- Reset (row 9) only on the throwaway save, when needed.
